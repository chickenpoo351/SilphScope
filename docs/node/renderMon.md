# renderMon

This file handles the ins and outs of the Node based `renderMon` function.

# Description

Renders a single mon and any of its related battle graphics from a supported ROM. includes the following graphics:

- Mon front sprite
- Mon back sprite
- Shiny palette mon front sprite
- Mon icons
- Mon footprints
